# awesome-noai
List of awesome open source software without ai code. It's infeasible to avoid all ai-assisted software, but this list aims to inform people who value ai's harms of a potential product. For a list of software some people would want to avoid, see [bad.md](bad.md)  
Codebases that do not have a permanent anti-ai policy are prefixed with `🤔`.
